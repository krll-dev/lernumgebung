# AGENTS.md

## Zweck dieses Repositories

Dieses Repository dient aktuell als Arbeits- und Lernumgebung fuer ein Vorhaben mit folgendem Ziel:

- Einstieg in Informatik/Programmierung aus einem HR-Kontext
- Aufbau von technischem Verstaendnis mit Praxisnaehe
- mittelfristige Ausrichtung auf IT-/Teilprojektleitung statt klassischer Entwicklerkarriere als Selbstzweck

## Wichtige Quelle

Vor Empfehlungen, Plaenen, Aufgabenlisten oder Strukturvorschlaegen in diesem Repository immer zuerst [`einstieg-in-programmierung.md`](/Users/kirill.esau/dev/lernumgebung/einstieg-in-programmierung.md) beruecksichtigen. Die Datei ist die aktuelle Deep-Research-Grundlage fuer das Vorhaben und gilt hier als inhaltliche Leitlinie, solange der Nutzer nichts anderes festlegt.

## Inhaltliche Leitplanken aus der Research-Datei

Die zentrale empfohlene Reihenfolge ist:

1. SQL
2. Python
3. Web- und API-Grundlagen
4. Git/GitHub
5. Java spaeter
6. Angular deutlich spaeter, nicht als Einstieg

Weitere Kernaussagen, die bei Hilfestellungen beruecksichtigt werden sollen:

- SQL ist der beste erste Einstieg, weil es fuer den vorhandenen HR-/Tabellen-Kontext die niedrigste Huerde und den schnellsten Praxisnutzen bietet.
- Python ist die erste empfohlene Programmiersprache, weil damit schnell kleine Automatisierungen und Datenverarbeitung moeglich sind.
- Web-Grundlagen dienen hier primaer dem technischen Verstaendnis fuer Zusammenarbeit und Projektgespraeche, nicht als sofortiger Weg in Frontend-Frameworks.
- Git und GitHub sind frueh relevant, weil sie technische Zusammenarbeit, Aufgabenorganisation und Software-Prozesse sichtbar machen.
- Java ist relevant, aber nicht als erste Sprache.
- Angular soll anfangs bewusst ignoriert werden.

## Empfehlungen fuer kuenftige Unterstuetzung

Wenn in diesem Repository Lernplaene, Uebungen, Projekte oder Dateien erstellt werden, dann moeglichst:

- praxisnah und niedrigschwellig beginnen
- mit kleinen, sichtbaren Erfolgen arbeiten
- Inhalte auf den HR-/Reporting-/Datenkontext beziehen
- interaktive und konkrete Uebungen gegenueber abstrakter Theorie bevorzugen
- keine unnoetig komplexen Setups oder Toolchains als ersten Schritt einbauen

Passende Mini-Projekte sind zum Beispiel:

- SQL-Datenbank fuer Bewerberstatus, Stellen, Interviews oder Absagen
- Python-Skripte fuer CSV-Auswertungen, Schulungen, Fehlzeiten oder Reporting
- einfache Uebungen zu APIs, JSON und HTTP erst nach SQL/Python-Grundlagen
- GitHub-Boards, Issues oder Lern-Backlogs zur Strukturierung des Lernwegs

## Technischer Kontext aus der Analyse

Die Research-Datei empfiehlt als pragmatische Startumgebung:

- Lenovo-Laptop als Hauptgeraet
- Raspberry Pi 3 B+ nur als Nebenprojekt, nicht als primaere Lernmaschine
- leichtgewichtiges Linux, bevorzugt Linux Mint Xfce
- SQLite plus DB Browser for SQLite
- Python
- Git
- einfacher Editor; spaeter bei Bedarf VS Code

## Arbeitsweise fuer Agents

Bei neuen Vorschlaegen in diesem Repository:

- nicht automatisch mit Java, Angular oder schweren Frameworks starten
- zuerst pruefen, ob SQL oder Python das naechste sinnvolle Lernziel ist
- Empfehlungen moeglichst konkret, umsetzbar und in kleine Schritte zerlegt formulieren
- lieber wenige gute naechste Schritte liefern als viele gleichwertige Optionen
- bei Zielkonflikten zwischen "schnell Entwickler werden" und "schnell technisches Verstaendnis fuer Projektleitung aufbauen" den zweiten Pfad priorisieren

## Pflegehinweis

Wenn sich Zielbild, Reihenfolge oder technische Rahmenbedingungen des Vorhabens aendern, diese Datei zusammen mit der Research-Datei aktualisieren.
